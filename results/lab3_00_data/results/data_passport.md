## 8. Смещения выборки (аналог survivorship bias)

- Состав станций фиксирован (424 комплекса ВКР) на весь период; открытые позже станции не появляются, закрытые на ремонт остаются с нулевыми входами — их спрос не перераспределяется на соседние станции.
- Расписание с поправками отражает плановые работы, но не сбои в реальном времени: фактическое число поездов в день сбоя ниже расписания, а в среде — нет.
- Спрос — входы: пересадки внутри системы не учитываются; нагрузка магистралей с пересадочными потоками занижена и компенсируется только калибровкой κ.

## 9. Схема предобработки

1. Полная сетка часов; пропуски — линейная интерполяция (≤ 6 ч).
2. Станция → группы линий по названию комплекса; входы делятся пропорционально поездам по расписанию.
3. Расписание: отправления с начальной станции (stop_order = 1) по часу отправления, среднее двух направлений; сутки без расписания — типичное расписание типа дня по train.
4. Прогнозы m4w и norm_level по ряду группы (коэффициенты norm_level — только train); гибрид ВКР — сумма прогнозов станций.
5. Калибровка κ, нормировки, парк и пропускная способность — только по train (кроме пропускной способности — максимум расписания).
